# PoultryTrack — Sistem Kasir & Manajemen Lapak Pasar

Aplikasi web kasir (*Point of Sale*) dan pembukuan piutang (*bon tempo*) luring (*offline-first*) yang dirancang khusus untuk pedagang lapak ayam potong tradisional.

## Fitur Utama
- **Kasir Timbangan Cepat**: Input ekor, kilogram timbangan, dan pemilihan potongan karkas (*Utuh, 4 Potong, Fillet, Tanpa Kulit*).
- **Display Antrean Juru Potong (*Cutting Queue*)**: Monitor spesifikasi potongan pesanan yang sedang diproses.
- **Buku Piutang Digital (*Bon Tempo*)**: Kartu saldo berjalan mitra langganan warung makan dan penagihan via WhatsApp.
- **Manifes Pasokan Karkas**: Pencatatan faktur ayam masuk dari peternak (*UD. Cheyloo Farm Kamal*).
- **Rekap Kas Laci**: Pencocokan fisik uang di laci meja sebelum lapak tutup.
- **100% Offline-First**: Bekerja tanpa internet menggunakan *localStorage* peramban.
